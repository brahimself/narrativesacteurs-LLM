\section{Protocole de lecture}
Les resultats ci-dessous sont calcules sur le split final
\texttt{autotrain\_pair\_score\_en\_fr\_en\_hard\_final}
(\(N_{test}=208\), \(52\) positifs, \(156\) negatifs).

Le seuil operationnel est selectionne sur validation (best F1), puis applique tel quel sur test.

Interpretation:
\begin{itemize}[leftmargin=2em]
  \item Les deux modeles apprennent correctement (train/loss en baisse).
  \item MPNet presente une validation finale nettement plus basse
        (\(\sim 1.08\) vs \(\sim 2.77\)), donc une generalisation plus robuste.
  \item allMiniLM reste stable, mais avec un ecart train/validation plus eleve.
  \item Cette lecture est coherente avec les metriques finales:
        MPNet fine-tune est devant en \(F1@seuil\) et \(Recall@1\).
\end{itemize}

\section{Interpretation}
\begin{itemize}[leftmargin=2em]
  \item Le fine-tuning ameliore nettement les deux familles de modeles face a leur baseline.
  \item MPNet fine-tune est le meilleur compromis global sur ce test
        (\(F1=0.9811\), \(Acc=0.9904\), \(Recall@1=1.0000\)).
  \item allMiniLM fine-tune reste performant, mais legerement en dessous du MPNet fine-tune.
  \item Le calibrage du seuil est indispensable: a seuil fixe \(0.5\), les performances sont inferieures pour plusieurs modeles.
\end{itemize}
